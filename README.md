### Featured Projects

- **[Qareeblak](https://github.com/AmjedKhaled165/Qareeblak)** — Unified service marketplace & real-time delivery platform featuring live courier GPS tracking, WebSocket message bus, PostgreSQL indexing, and automated WhatsApp invoice dispatch (`Next.js`, `Node.js`, `React Native`, `Socket.io`, `PostgreSQL`, `Docker`).
- **[Oryx (Stock M8)](https://github.com/AmjedKhaled165/Oryx)** — Autonomous retail shelf empty-space detection and inventory monitoring system combining custom YOLO models with Arduino motor rail hardware and real-time spatial analysis (`YOLO`, `OpenCV`, `Python`, `Arduino C++`).
- **[ShadowDesk](https://github.com/AmjedKhaled165/ShadowDesk)** — Systems-level Windows desktop utility for real-time window cloaking and privacy during full-screen sharing sessions using native Desktop Window Manager exclusion APIs (`Rust`, `Win32 API`, `DWM`).
- **[Smart-Fishing](https://github.com/AmjedKhaled165/Smart-Fishing)** — Deep learning and telemetry system for real-time marine object classification and environmental monitoring utilizing transfer learning and OpenCV video pipelines (`Python`, `VGG-16`, `OpenCV`, `IoT`).
- **[Flask Image Processing](https://github.com/AmjedKhaled165/Flask_Image-Processing)** — Full-stack image processing web application providing image enhancement routines, dominant color extraction, and user profile media management (`Python`, `Flask`, `MongoDB`, `Pillow`).
- **[Amjed N8N Projects](https://github.com/AmjedKhaled165/Amjed_N8N_Projects)** — Production-grade AI workflows, LLM tool-calling pipelines, and automated business integrations (`n8n`, `Webhooks`, `AI Agents`).
