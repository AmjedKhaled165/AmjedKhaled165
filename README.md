## Featured Projects

- **[Qareeblak](https://github.com/AmjedKhaled165/Qareeblak)**  
  Unified service marketplace and real-time on-demand delivery ecosystem featuring live courier GPS tracking, WebSocket message bus, PostgreSQL indexing, and automated WhatsApp invoice dispatch.  
  *Stack: Next.js, Node.js, Express, React Native (Expo), Socket.io, PostgreSQL*

- **[Oryx (Stock M8)](https://github.com/AmjedKhaled165/Oryx)**  
  Autonomous retail inventory monitoring and empty-shelf detection system combining custom YOLO models with Arduino motor rail hardware and real-time spatial analysis.  
  *Stack: YOLO, OpenCV, Python, Arduino C++, Roboflow*

- **[ShadowDesk](https://github.com/AmjedKhaled165/ShadowDesk)**  
  Systems-level Windows desktop utility for real-time window cloaking and privacy during full-screen sharing sessions using native Desktop Window Manager exclusion APIs.  
  *Stack: Rust, Win32 API, DWM, Windows Shell*

- **[Smart Fishing](https://github.com/AmjedKhaled165/Smart-Fishing)**  
  Deep learning and telemetry system for real-time marine object classification and environmental monitoring utilizing transfer learning and OpenCV video pipelines.  
  *Stack: Python, TensorFlow, Keras, VGG-16, OpenCV*

- **[Flask Image Processing Service](https://github.com/AmjedKhaled165/Flask_Image-Processing)**  
  Full-stack web application providing image enhancement routines, dominant color extraction, and user profile media management.  
  *Stack: Python, Flask, MongoDB, MongoEngine, Pillow*
